# Retail Inventory Analytics

## Project Overview

This project analyzes retail inventory data using Python and Google Colab. The objective is to evaluate inventory performance, identify low-stock products, analyze supplier contributions, and generate business insights for better inventory management.

## Dataset Information

The dataset contains:

* Product ID
* Product Name
* Category
* Supplier Name
* Unit Cost
* Retail Price
* Opening Stock
* Units Sold
* Closing Stock
* Reorder Point
* Stock Status

Total Records: 1000

### Data Understanding

### Exploratory Data Analysis

* Category-wise product count

* Top 10 best-selling products
* Top 10 low-stock products
* Supplier-wise inventory distribution

### Visualizations

* Bar Chart

* Line Graph
* Correlation Heatmap

## Key Business Insights

1. Several products require immediate replenishment due to low stock levels.
2. Fast-moving categories contribute significantly to overall sales.
3. Some products show signs of slow-moving inventory.
4. Supplier dependency risk exists due to concentration among a few suppliers.
5. High-profit products should receive priority inventory allocation.
